**⌥⌘U**가 모니터링을 엽니다. 여기 있는 모든 수치는 이용자의 컴퓨터에서 계산되며, 어디에도 업로드되지 않습니다.

## AI 사용량

비용, 호출 수, 캐시 적중률, 토큰을 모델·프로젝트·도구별로 보여줍니다. 수치는 에이전트 CLI가 이미 디스크에 기록해 둔 대화 파일에서 나옵니다.

집계는 줄을 더하는 것만큼 단순하지 않습니다. Claude Code는 콘텐츠 블록마다 JSONL 한 줄을 쓰기 때문에 하나의 API 응답이 같은 message id로 여러 번 나타나며, 이를 그 id로 중복 제거합니다. Codex는 응답마다 사용량 레코드 하나를 response id로 기록합니다. Agentty는 각 형식을 따라가므로 한 응답이 한 번만 계산됩니다.

Claude 모델 가격은 내장되어 있습니다. Codex가 쓰는 모델처럼 그 외의 모델은 `~/.agentty/pricing.json`에 가격을 적으면 함께 계산됩니다.

```json
{
  "some-model": { "input": 1.25, "output": 10.0, "cacheRead": 0.125 }
}
```

가격은 100만 토큰당 USD입니다. `cacheRead`, `cacheWrite`, `cacheWrite1h`는 선택이며 각각 입력 단가의 10%, 125%, 200%가 기본값입니다.

> [!NOTE]
> 로컬 파일로 계산한 참고용 추정치입니다. 실제 금액은 제공자의 청구서입니다.

## 프로세스

지금 컴퓨터에서 실행 중인 AI 프로세스와, 무엇이 그것을 시작했는지 보여줍니다. 멈춘 줄 알았는데 토큰이 계속 소모될 때 유용합니다.

## 프록시

각 탭이 무엇과 통신하는지 보여주는 캡처 프록시입니다. 캡처를 켜고, 탭을 열고, 엔드포인트로 필터링하면 됩니다.

- **캡처가 켜진 상태에서 연 탭**은 이용자의 컴퓨터에서 동작하는 프록시를 경유합니다.
- HTTPS는 암호화된 채로 유지됩니다. 호스트, 포트, 전송량, 소요 시간만 기록되며 인증서를 설치하지 않고 아무것도 복호화하지 않습니다.
- 암호화되지 않은 HTTP는 메서드, 경로, 응답 상태만 기록하고 헤더나 본문은 기록하지 않습니다.
- 기록은 메모리에만 있고, 개수가 제한되며, 디스크에 쓰이지 않고, Agentty를 종료하면 사라집니다.

캡처를 끄면 기록이 멈춥니다. 이미 프록시를 받은 탭은 네트워크가 끊기지 않도록 계속 그것을 사용합니다.
