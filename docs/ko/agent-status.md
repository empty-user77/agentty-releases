---
title: 에이전트 상태
description: Agentty가 각 에이전트의 상태를 아는 방법과, 그것을 알려주는 방식.
---

Agentty는 실행한 에이전트를 지켜보면서, 각각이 작업 중인지 끝났는지 나를 기다리는지 보여줍니다.

## 상태가 보이는 곳

- **사이드바** — 각 워크스페이스 행이 그 안의 에이전트 상태를 나타냅니다.
- **페인 테두리** — 에이전트가 질문하거나 권한을 요청하면 켜지고, 클릭할 때까지 유지됩니다.
- **에이전트 페인 위의 상태 바** — 모델, 컨텍스트 창, 사용 한도, 브랜치, 폴더.
- **알림** — 에이전트가 끝나거나 답을 기다릴 때. 클릭하면 해당 페인이 열립니다.
- **⇧⌘U** — 가장 최근의 미확인 페인으로 이동.
- **미니 모드와 메뉴 바** — 창을 앞에 두지 않고도 상태를 확인.

## 상태의 종류

| 상태 | 의미 |
|---|---|
| 작업 중 | 도구를 실행하고 있음 |
| 생각 중 | 턴이 열린 상태, 도구 호출 사이 |
| 입력 대기 | 질문했거나 권한을 요청함 |
| 완료 | 턴이 끝남 |
| 유휴 | 실행 중인 것 없음 |

## 동작 방식

Agentty는 페인을 시작할 때 명령줄로 상태 훅을 전달합니다. 에이전트는 이용자 계정만 접근할 수 있는 로컬 전용 소켓으로 상태를 보고합니다. 프로젝트나 에이전트의 설정 파일에는 아무것도 기록하지 않습니다.

## 알림

**설정 → 알림**에서 정합니다.

- 에이전트가 끝나거나 입력이 필요할 때의 시스템 알림.
- Agentty가 맨 앞에 있을 때도 알릴지 여부.
- 질문과 권한 요청은 해당 페인을 보고 있지 않는 한 항상 알립니다.

### 휴대폰으로 받기

같은 화면에서 **Slack**, **Discord**, **Telegram**을 연결하면 자리를 비웠을 때도 질문이 도달합니다. 에이전트가 나를 필요로 할 때만 보낼지 완료 시에도 보낼지, 그리고 에이전트가 무엇을 물었는지 포함할지 선택할 수 있습니다.

웹훅 주소와 봇 토큰은 설정 파일이 아니라 운영체제의 자격 증명 저장소에 보관됩니다.
