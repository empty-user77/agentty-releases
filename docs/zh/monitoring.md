**⌥⌘U** 打开监控。这里的一切都在你的机器上计算，不会上传。

## AI 用量

费用、调用次数、缓存命中率和令牌，按模型、项目和工具细分。数字来自智能体 CLI 已经写在磁盘上的会话记录。

统计并不只是把行加起来。Claude Code 每个内容块写一行 JSONL，因此同一次 API 响应会以相同的 message id 出现多次，这些会按该 id 去重。Codex 则是每次响应一条用量记录，以 response id 为键。Agentty 遵循各自的格式，所以一次响应只计一次。

Claude 模型的价格是内置的。其他模型（例如 Codex 使用的那些）可以在 `~/.agentty/pricing.json` 中填入价格，就会一并计算：

```json
{
  "some-model": { "input": 1.25, "output": 10.0, "cacheRead": 0.125 }
}
```

价格单位是每百万令牌的美元。`cacheRead`、`cacheWrite` 和 `cacheWrite1h` 为可选，默认分别是输入价的 10%、125% 和 200%。

> [!NOTE]
> 这些是根据本地文件计算的估算值，仅供你自己参考。真正的数字以提供方的账单为准。

## 进程

此刻在你机器上运行的 AI 进程，以及是什么启动了它们。当你以为已经停下、token 却还在消耗时很有用。

## 代理

一个抓取代理，列出你的标签页在和谁通信：开始抓取、打开标签页、按端点筛选。

- **在抓取开启期间打开的标签页**会经过运行在你自己机器上的代理。
- HTTPS 保持加密。只记录主机、端口、字节数和耗时 —— 不安装证书，不解密任何内容。
- 对明文 HTTP，只记录方法、路径和状态码，绝不记录头部或正文。
- 记录只存在于内存中，数量有上限，不会写入磁盘，Agentty 退出即消失。

停止抓取即停止记录。已经拿到代理的标签页会继续使用它，以免网络中断。
